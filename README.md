# PropertyDamageAlerts

A Python system that:

1. **Finds Florida property disasters** – fire, wind, and structural damage – by querying FEMA's Open Data API and news sources.
2. **Reaches out to property owners** introducing the value of a Licensed Public Adjuster in the State of Florida.
3. **Markets to HOAs** – maintains an HOA registry and sends branded outreach to board members.

---

## How It Works

```
Data Sources (FEMA / NewsAPI)
        │
        ▼
Disaster Filter (fire, wind, structural)
        │
        ▼
Property Owner Lookup (county appraiser APIs)
        │
        ▼
Outreach (email / letter) → property owners
        │
HOA Registry ─────────────────────────────▶ HOA marketing emails
```

### Data Sources

| Source | What it provides | Key |
|--------|-----------------|-----|
| [FEMA Open Data](https://www.fema.gov/about/openfema/data-sets) | Federal disaster declarations for Florida | None (public) |
| [NewsAPI](https://newsapi.org) | Local news articles about fires, wind/structural damage | Free API key |

### Damage Types Detected

- **Fire** – house fires, wildfires, structure fires
- **Wind** – hurricanes, tornadoes, tropical storms, severe storms
- **Structural** – flooding, collapses, earthquake, landslide, dam breaks

## Quick Start

### 1. Install

```bash
pip install -e .
```

### 2. Configure

Copy the example environment file and fill in your details:

```bash
cp .env.example .env
# Edit .env with your firm info, SMTP credentials, and API keys
```

Key settings in `.env`:

```
FIRM_NAME=Your Public Adjusting Firm
ADJUSTER_NAME=Your Name
ADJUSTER_LICENSE=W123456
ADJUSTER_PHONE=(555) 555-5555
ADJUSTER_EMAIL=adjuster@yourfirm.com
FIRM_WEBSITE=https://yourfirm.com

SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USERNAME=your_email@gmail.com
SMTP_PASSWORD=your_app_password

NEWS_API_KEY=your_newsapi_key_here
```

## Usage

### Find disasters and send owner outreach

```bash
# Preview messages (no email sent)
property-damage-alerts disasters --dry-run

# Search the last 90 days, fire and wind only
property-damage-alerts disasters --days-back 90 --damage-types fire,wind

# Live send (requires SMTP configured in .env)
property-damage-alerts disasters --days-back 365
```

### HOA marketing

```bash
# Import HOAs from a CSV file
property-damage-alerts hoa import-csv hoas.csv

# List registered HOAs
property-damage-alerts hoa list

# Send marketing emails (dry-run first!)
property-damage-alerts hoa market --dry-run
property-damage-alerts hoa market
```

#### HOA CSV format

```csv
name,county,city,contact_name,contact_email,contact_phone,mailing_address,num_units,notes
"Sunset Palms HOA",Hillsborough,Tampa,"John Smith",jsmith@example.com,(813) 555-1234,"100 Sunset Blvd Tampa FL 33601",200,""
```

## Property Owner Lookup

Owner lookup is performed via Florida county property appraiser APIs.  Configure the endpoint for a county by setting:

```
PROPERTY_APPRAISER_BASE_URL=https://<county-appraiser-api-base>
PROPERTY_APPRAISER_API_KEY=<optional-key>
```

Each county runs its own portal. If no URL is set, the pipeline skips owner lookup and logs the incident for manual follow-up.
